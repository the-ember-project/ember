## Could change a result
- **"M3 met on GSM8K" (m3-dpo2 and m3-dpo3), and m3-vs-3b.** Both replications, and the 3B comparison, score held-out GSM8K *train* items. These look much easier than the test set: BASE scores 80.5–81.7% on them against ~68% on test, and 3B scores 92.3% against 75.7%. That gap suggests Qwen2.5 saw these items in training. The one run scored on the test set (m3-dpo, full 1319 questions) had its primary MIX arm fail (+2.35, p=0.072). So "M3 met on GSM8K" rests on a likely contaminated distribution, and so does the "closes 50% of the gap" figure. What would settle it: a greedy eval of the saved MIXR adapters from m3-dpo2 and m3-dpo3 on the GSM8K test set.
- **"At matched compute, the 2× model beats 1.5B+G3 on both MATH and GSM8K" (sessions #21–22).** On MATH the gap is −5.5 with p=0.16, which is not significant, and the agent itself marked the run compromised because the boxed rate was 84.5% against an 85% threshold. A failed non-inferiority test does not show superiority. Only GSM8K is significant (p=0.044), and that is on the agent's dev slice, where G3's own gain didn't replicate (+1.3). The supported wording is "1.5B+G3 did not reach 3B greedy". The "3B is better" part holds only for GSM8K.
- **"G3 alone and label-free DPO alone each close about half of the 1.5B→3B gap" (session #23).** On GSM8K, G3 closes (69.7−68.3)/(75.7−68.3) ≈ 19% of the gap. "About half" holds only for MATH (45%). The DPO figure comes from different items (train split) and is not compute-matched. Reword the claim.
- **"Label-free self-training iterates" (m3-gw-iter H1).** R2 trained on 2.3× more traces than R1. The caveat is in the notes, but the headline still says "iterates and compounds". Until m3-gw-eq reports, the supported claim is "R2 (more data, better teacher) beats R1". H2 (G3(R2) > G3(BASE)) stands.
- **"The gridwalk gain comes from the program format" (gridwalk2 explore2, gridwalk2-3b at 96.7%, the PALV teacher).** The material doesn't show the one-shot PAL demo. If that demo is a reusable direction-vector simulator, while the CoT demo is a worked trace, then PAL is partly copying an algorithm the prompt hands it, and the conclusion becomes "the demo supplies a solver" rather than "the format is better". To settle it, diff the PAL outputs against the demo code and report how many are the demo program with only the action list swapped.

## Prior work
The paper-search tool was rate-limited on both arXiv and Semantic Scholar, so these came from web search.
- **G3 / CoT+program voting.** Zhao et al., *Automatic Model Selection with LLMs for Reasoning* (https://arxiv.org/abs/2305.14333), use an LLM to choose between CoT and PAL. XoT (https://arxiv.org/abs/2310.14628), which the agent already cites, plans, verifies and switches between formats. Combining CoT and PAL is therefore known. What looks new: a cheap, greedy-anchored version measured from 0.5B to 3B on quantized models, with token costs, and the measured explanation that on MATH, at equal voter count, PAL voters buy *cost* rather than accuracy (math-sc4).
- **Cross-format label-free self-training.** TTRL (https://arxiv.org/abs/2504.16084) trains on majority-vote pseudo-labels, and ScPO (https://arxiv.org/abs/2411.04109) runs DPO on consistency-based preferences. T³RL, which the agent found, weights votes using code-execution evidence. Self-consistency pseudo-labelling is therefore known. Two things look new: using the program vote as the teacher for *CoT traces* at 1.5B, and the paired evidence that a same-format majority (the ScPO/TTRL-style label) is unreliable or useless at this scale (+3.1/−7.9/−1.0; COTM +1.0). The agent's notes don't overclaim here.
- **Small model + inference tricks vs a bigger model.** Snell et al. (https://arxiv.org/abs/2408.03314) report that FLOPs-matched test-time compute can beat a much larger model, but only on problems the small model already partly solves. Wu et al. (https://arxiv.org/abs/2408.00724) find small models with advanced inference methods Pareto-optimal. The agent's negative result uses simple 4-voter voting and a 2× size gap. It fits Snell's caveat and contrasts with Wu's finding, so it is a useful small-scale data point, but these papers should be cited.
