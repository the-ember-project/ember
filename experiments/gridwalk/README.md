# gridwalk — does CoT+program voting carry to a *generative* state-tracking task? (M2, stronger version)

Earlier M2 evidence (BBH) was multiple choice. Here the answer is free-form: a robot starts at (0,0) facing north and
follows 6 relative instructions ("walk forward N steps", "turn left/right", "turn around"); the model outputs the final
(x, y). Exact checker; tasks generated by `run.py:make_task(i, steps=6, seed=777)`. Answer space is large, so voting
cannot win by chance agreement. Qwen2.5-1.5B-Instruct Q4_K_M, llama-cpp, CPU lab.

## Pilot (exploratory, session #11, indices 5000–5207, not reused)
- 10 steps: greedy CoT 0/8, greedy PAL 0/8. 7 steps: CoT 1/8, PAL 3/8. 5 steps: CoT 2/8, PAL 1/8.
- Failure mode (read outputs): the model gets relative-turn semantics wrong ("turn left" from north → east), in CoT and
  when writing code (hard-coded wrong headings). Sampled answers scatter widely; pass@11 on a 2-q smoke was 2/2.
- Chosen: 6 steps, prompts unchanged from the pilot (generic, no turn-table hints).

## Design
- Test indices 0–199 (n=200), task seed 777. Per question: greedy CoT (`cot_greedy.jsonl`), 5 CoT samples T=0.7
  seed 81 (`cot_s.jsonl`), 5 PAL samples T=0.7 seed 82 (`pal_s.jsonl`). `run_lab.sh` runs chunks of 25, resumable.
- `analyze.py`: plurality vote over parsed (x,y); abstentions (no parse / crash) dropped; ties → earliest sample
  (order as listed). Exact two-sided sign test on paired discordant questions. Token cost relative to greedy.

## Prediction (written before any test-index run)
Verdicts only at n=200 (if the first lab run stops early, it is resumed; no interim verdicts).
- **H1 (primary):** MIX10 = vote(5 CoT + 5 PAL samples) − greedy CoT **≥ +3 points AND sign-test p < 0.05.**
  Predicted +5 (range −3 to +12); ~45% chance. Greedy predicted ~22% (range 10–35).
- **H2:** G3 = vote(greedy CoT + 3 PAL), greedy wins ties, − greedy **≥ +3 AND p < 0.05.** Predicted +1 (range −3 to +5);
  ~20% chance (PAL is weak here and 2 PAL samples must agree to overturn greedy).
- **H3 (equal-count control, the reviewer's question):** vote(3 CoT + 2 PAL samples) − vote(5 CoT samples) **≥ 0**
  (direction; p reported). Predicted +1 (range −5 to +6); ~55% chance.
- Reported, not pass/fail: single CoT/PAL sample, vote(5P), vote(2C+3P), pass@11, PAL abstain rate, cost.
