# m3-gw-eq: is round 2's gain a better teacher or just more data? (Kaggle GPU)

**Why.** m3-gw-iter: R2 (round-1 traces + round-2 traces labelled by the R1 model) beat R1 by +5.2 (p=3e-6), but R2
trained on 2.3× more traces (2309 vs 1012), so "iteration helps" is confounded with "more data helps". This job holds
data size and task pool fixed and varies only the teacher of the second half.

## Design
Same code, model (Qwen2.5-1.5B-Instruct), PALV filter (CoT samples agreeing with the plurality of 5 program samples,
≥3 votes, ≤2 traces/task), LoRA recipe, and eval sets as `../m3-gw-iter/` (copied `run.py`, `gw.py`).
1. gen1: base model on pool 1 (1500 tasks, seed 9001, 8 CoT + 5 PAL) → train **R1** (teacher only, not evaluated).
2. gen2: R1 model on pool 2 (1500 tasks, seed 9004, 4 CoT + 5 PAL).
3. gen3 (new): **base** model on the same pool 2, same sampling budget (4 CoT + 5 PAL).
4. Train from base, n2 = min(#gen2 traces, #gen3 traces), each side randomly subsampled to n2 (seed 9002):
   - **R2EQ** = pool-1 traces + n2 pool-2 traces labelled/generated by R1 (iteration).
   - **R1X** = the same pool-1 traces + n2 pool-2 traces labelled/generated by base (more data, no iteration).
5. Eval BASE, R2EQ, R1X: greedy CoT on 600 fresh 10-step tasks (seed 9005), 300 14-step (9006), 300 GSM8K; G3 on gw10.
CPU smoke (0.5B, HF backend, fake labels, all 6 phases) passed session #17. Queued on Kaggle at 400 min (est. ~345).
Note the R1 teacher is retrained (same seeds as m3-gw-iter, but not bit-identical), so gen2 is a fresh draw.

## Prediction (written session #17, before any run)
- **H1 (confirmatory, primary):** R2EQ − R1X greedy gw10 ≥ +2.0 AND sign-test p < 0.05 (n=600). Predicted **+3**
  (range −1 to +7). Reasoning: R1 teacher has higher CoT sample accuracy (traces 95% correct in both rounds, but R1
  labels ~1.4× more tasks and its traces are on harder tasks), so I expect a real but smaller effect than the +5.2.
- **H2 (confirmatory):** R1X − BASE gw10 ≥ +15 (replication of the PALV gain at more data). Predicted +22.
- **H3:** GSM8K drift ≥ −3 for both arms.
- Reported: pool-2 label precision and coverage for both teachers, gw14 and G3 differences, trace counts.
- If H1 fails with diff near 0, the honest reading is that round 2's gain in m3-gw-iter was mostly data volume.
